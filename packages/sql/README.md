# packages/sql

Optional SQL reporting (flag `enableSql`): Aurora Serverless v2 PostgreSQL through the RDS **Data API**, with
**Drizzle ORM**. Used by `functions/sql-reporter` (writes, from the Bookings stream) and `api` (`GET /api/admin/reports`).

| File | Job |
|---|---|
| `src/schema.ts` | Tables `events` and `bookings` (normalized, foreign key, indexes) |
| `src/client.ts` | `createDb()` over the Data API; `isDatabaseResuming()` for scale-to-zero wake-ups |
| `src/reports.ts` | Revenue per event (JOIN + GROUP BY), bookings per day |
| `migrations/` | SQL migrations generated by drizzle-kit (committed, applied by sql-reporter) |

```bash
pnpm --filter @ticketlite/sql generate   # after changing src/schema.ts: writes a new migration
pnpm --filter @ticketlite/sql test       # checks the generated SQL (no database)
```

**Safe migrations:** only additive changes in one step (new tables, nullable columns, new indexes). To rename or drop,
use expand → migrate data → contract over several deploys, so old and new code both work during a deploy.
See docs/adr/0008-sql-reporting.md.
